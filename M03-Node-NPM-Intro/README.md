# Module 3 · Node.js and npm Intro

This project uses Node's built-in HTTP module to serve an ASCII cow generated by the `cowsay` npm package.

## Run the web server

From this directory, run these commands with Node.js and npm installed.

```powershell
npm ci
npm start
```

Open [http://127.0.0.1:3000/](http://127.0.0.1:3000/) to see the server's response. Press Ctrl+C in the terminal to stop the server.

## Run cowsay in the terminal

```powershell
npm run cowsay -- "Damien Torres"
```
