# Module 4 · Intro to React

This project follows [Bro Code's React tutorial](https://www.youtube.com/watch?v=CgkZ7MvWUAA) through the rendering lists chapter. The examples demonstrate JSX components, CSS, props with default values, conditional rendering, and reusable lists with stable keys. The fruit examples also use filtering and sorting.

## Run locally

```sh
npm ci
npm run dev
```

## Deploy to GitHub Pages

Run `npm run deploy` from this directory after pushing the source. Vite builds to `dist`, and the deployment publishes that folder under `M04-React-Tutorial` on the `gh-pages` branch. In GitHub Pages settings, select `gh-pages` and `/ (root)` if that branch is the intended publishing source.
